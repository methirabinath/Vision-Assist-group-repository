# VisionAssist Backend

This is the backend server for the VisionAssist system, which supports user authentication, real-time alerts, and role-based access control.

---

## Technologies Used

- Node.js
- Express.js
- MongoDB (Atlas)
- Mongoose
- JWT Authentication
- Socket.IO

---

## Features

- User Registration and Login
- Secure password hashing using bcrypt
- JWT-based authentication
- Protected routes using middleware
- Role-based access (Admin / User)
- Block and unblock users
- Fall detection alerts
- SOS emergency alerts
- Real-time alert broadcasting using Socket.IO
